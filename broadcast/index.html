使用说明

欢迎使用语音广播系统

本系统用于超市 / 门店的语音播报与背景音乐管理。支持 TTS 文字转语音、音频导入、按时段自动调度等功能。

快速上手

  1. 在「编辑文字转语音」中新建 TTS 项目或导入本地音频文件；
  2. 把项目加入「播放列表」，设置间隔与生效时段；
  3. 点击右上角「点击启动」开始自动调度。
  4. 「背景音乐」可进行音乐设置（推荐使用）。

常见问题

Q：TTS 没有声音？
A：点右上角「语音包」检测中文语音，推荐使用 Microsoft Edge浏览器。检查是否已经启动调度，播放列表是否「启用」音频，是否在「生效时段」内。

Q：如何打开背景音乐？
A：点右上角红色圆形音乐按钮，可粘贴 URL 或上传本地文件。

浏览器兼容性提示
当前环境：- · -

本系统的语音合成功能依赖浏览器调用系统语音引擎。在非 Edge 浏览器（如 Chrome、Firefox、Safari、国产浏览器等）中，您可能遇到以下问题：

  • ❌ 语音下拉框为空，找不到"晓晓"等中文音色
  • ❌ TTS 试听时没有声音，或只用英文腔调读中文
  • ❌ 朗读卡顿、断断续续，或播报中途突然停止
  • ❌ 切换到其他标签页后，广播被浏览器自动暂停

推荐直接使用 Microsoft Edge 浏览器打开本系统，无需任何额外安装，且内置"晓晓"等高质量中文语音，稳定可靠。

如果坚持使用当前浏览器，请按以下步骤安装系统中文语音（Windows）：

  1. 打开 Windows 设置（按 Win + I）
  2. 进入 时间和语言 → 语言和区域
  3. 找到"中文（简体，中国）"，点击右侧 ⋯ → 语言选项
  4. 在"语音"区域，点击下载按钮安装以下语音包（推荐）：
    · Microsoft 晓晓（女声，自然）
    · Microsoft 云希（男声，自然）
  5. 安装完成后刷新本页面，再点"语音包"按钮验证

如果坚持使用当前浏览器，请按以下步骤安装系统中文语音（macOS）：

  1. 打开 系统设置 → 辅助功能 → 朗读内容
  2. 点击 系统语音 → 管理语音
  3. 找到"中文（中国大陆）"，勾选并下载 Tingting 或 Meijia
  4. 下载完成后刷新本页面

建议：直接安装并使用 Microsoft Edge 浏览器打开本系统，可跳过所有语音包配置步骤。

💡 建议操作：点击下方"用 Edge 打开"按钮，系统会自动用 Edge 浏览器重新打开本页面。
